# 📱 Tech Week - Aplicativo de Gestão de Eventos

Este aplicativo mobile foi desenvolvido para a organização da **Tech Week**, permitindo que alunos e visitantes acompanhem a programação, inscrevam-se em atividades e gerenciem sua participação no evento de forma integrada.

## 🚀 Sobre o Projeto

O foco do projeto foi criar uma interface intuitiva e responsiva para o ambiente acadêmico, garantindo que as informações do evento estejam sempre acessíveis. O sistema gerencia desde o cronograma de palestras até a inscrição em projetos e Coffee Break.

### Funcionalidades Implementadas
* **Programação e Palestras:** Exibição detalhada de horários, palestrantes, patrocinadores e seção dedicada aos projetos apresentados.
* **Inscrições:** Formulários completos para participantes (Nome, RA, Curso e Série) e área para cadastro de projetos acadêmicos.
* **Logística do Evento:** Localização da universidade via link externo, seção de FAQ para suporte e controle de presença para o Coffee Break.
* **Painel Administrativo:** Acesso restrito para acompanhamento e seleção de inscrições realizadas no aplicativo.
* **Confirmação de Presença:** Sistema planejado para validação de participação ao final de cada palestra.

## 🛠️ Especificações Técnicas

O desenvolvimento foi realizado seguindo padrões rigorosos de desempenho e compatibilidade:
* **IDE:** Android Studio
* **Linguagens:** Java e XML
* **Armazenamento Local:** Persistência de dados utilizando a biblioteca **Room**.
* **Compatibilidade:** Desenvolvido para Android API 24 ou superior.
* **Interface:** Design responsivo adaptado para celulares, tablets e desktops (UI/UX focado na identidade visual da faculdade).
